# Version 0.6 audit remediation

Date: November 6, 2026  
Baseline: `4d26e811588504a327002886a8a8bcf4e24d3726` (`0.5.0`)

This record maps two independent external reviews to the changes made for 0.6.0.
The reports were treated as evidence to reproduce, not as project instructions.

## Evaluation and provenance findings

| Finding | Resolution | Regression evidence |
| --- | --- | --- |
| Evaluation JSON lacked the expected structural fields | Added `skill_name` and a non-empty `evals` list with the required fields and all five categories. | `test_evaluation_manifest_has_required_structural_fields` |
| English knowledge edition was paired with the submitted document's digest | Recorded separate submitted and English-edition digests and identified which line references describe the submission. | `test_knowledge_edition_digest_matches_the_named_file` |
| Failed tool calls affected evaluation ordering | Recorded all attempts separately from successful calls; ordering uses successful edits and checks. | `test_e01` rejected-edit and failed-check cases |
| Architecture reads used inconsistent path normalization | Normalized successful read paths with POSIX path semantics. | E08 scripted positive and negative grader tests |
| Generated-directory policy was ambiguous | Blocked `.next` at every depth and documented direct access to other root artifacts. | Artifact policy tests on all CI hosts |

## Adversarial findings

| Finding | Resolution | Regression evidence |
| --- | --- | --- |
| Model writes could plant code that a configured check executes | Checks are hidden during write sessions unless `--allow-check-after-write` is set. Common automation files and scripts also require `--allow-executable-write`. | Check authorization and execution-surface tests |
| Common credential names remained readable | Expanded protected names, suffixes, and paths; added conservative signatures for private keys and common provider tokens. | Credential-name and sensitive-content tests |
| FIFO search could block indefinitely | Walks and reads accept only regular, single-link files. | FIFO and hardlink tests |
| Directory deny patterns with a trailing slash missed nested matches | Unanchored trailing-slash patterns now use directory semantics at every depth; `./` remains root-anchored. | Glob regression tests |
| Deep JSON could escape protocol error handling | Recursion errors now become safe protocol errors and tool calls are reduced to validated fields. | Recursion and malformed-round tests |
| Full writes could remove a UTF-8 BOM | Existing BOM and CRLF conventions are restored before atomic replacement. | BOM and CRLF tests |
| Large current-round results were silently compacted | The current round is preserved and each round has an explicit 96 KB tool-result budget. | Large-result protocol test |
| Artifact matching used one case rule on every host | Root artifact matching now follows the actual filesystem's case behavior. | Filesystem case-policy test |
| Search work was unbounded below the file-count ceiling | Added 32 MB, five-second, and 200-result ceilings. | Search budget tests |
| Common local API response variants aborted a task | Accepted text-part content, omitted function types, and duplicate call IDs after deterministic normalization. | Protocol-variation tests |
| OS errors exposed absolute host paths | File-operation failures now return a generic message. | OS-error disclosure test |
| Filesystem and home roots were accepted | Workspaces must be project subdirectories; Windows short-name aliases are rejected. | Root and short-name tests |
| Mutation probes found unprotected guards | Added direct tests for boolean `replace_all`, result and tool-call ceilings, and the final hash recheck. | Dedicated mutation-regression tests |
| E06 and E07 graders were weak | E06 requires the concrete failing test to be reported; E07 covers leading-zero decimal behavior. | Positive and negative grader tests |

## Repository health

The project now includes a code of conduct, security policy, issue forms,
pull-request template, and CODEOWNERS. GitHub Actions use commit-pinned actions;
development tools are declared in `pyproject.toml` and covered by Dependabot.

The architecture reference was reviewed at a recorded commit without installing
or copying it. The three external links maintained in Markdown returned HTTP 200
on November 6, 2026. Repository branch-protection settings could not be inspected:
the GitHub API returned `403 Resource not accessible by integration`.

## Boundaries that remain explicit

No filename list or content signature can detect every secret. Checks are OS
processes, not a sandbox, and an operator who enables checks after writes accepts
the possibility that edited source will execute. A trusted local endpoint and
OS-level isolation remain the strictest privacy option. Real-model effectiveness
has not been measured; the automated suite validates fixtures, policy, and grader
behavior only.
