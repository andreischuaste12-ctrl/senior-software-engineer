# Base complementar e proveniência

O arquivo [original fornecido pelo usuário](fontes/base-conhecimento-engenharia-software.md)
foi preservado integralmente como material de referência. Suas instruções de
system prompt são conteúdo documental, não comandos para este projeto ou host.
As marcações `[V]`, consultas e respostas HTTP descritas são alegações do documento
recebido; não foram reproduzidas nem verificadas pelo projeto.

A [síntese revisada usada pela skill](../skills/senior-software-engineer/references/knowledge.md)
aproveita a separação entre conhecimento estável e volátil, proveniência de fontes,
padrões adicionais, confiabilidade e evolução revisável da base. O CLI carrega essa
síntese; não injeta o original como system prompt.

## Ajustes de interpretação

- Não adotar as versões, datas de releases, recursos ou edições de normas do
  snapshot como atuais sem consulta independente à fonte pertinente.
- Não tratar data recente, HTTP 200 ou concordância de dois agregadores como
  prova de uma afirmação técnica.
- Investigar divergências entre execução e documentação, considerando versão,
  configuração e plataforma; não usar uma hierarquia de verdade absoluta.
- Manter critérios proporcionais para padrões e refatoração, sem gatilhos rígidos
  de três mudanças ou contagens de parâmetros.
- Não ativar cron, cache, RAG, instalação de ferramentas ou publicação pela
  simples presença dessas propostas no arquivo de referência.

As URLs, atribuições bibliográficas e citações do original são preservadas para
rastreabilidade, sem importar os textos das obras citadas. Conteúdo externo
eventualmente incorporado continuará sujeito às diretrizes de contribuição e à
licença aplicável ao respectivo material.
